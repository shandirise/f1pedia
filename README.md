# F1 Pedia

An information website about the **2023 Formula 1 season**, built with plain **HTML and CSS** as a
university course project (final exam) at Universitas Muhammadiyah Purwokerto.

**Live site:** https://shandirise.github.io/f1pedia/

## Pages

| Page | Content |
| --- | --- |
| Home | Introduction to the site |
| Schedule | The race calendar |
| Team | The constructors |
| Driver | The driver line-up with portraits and race numbers |
| Track | The circuits |
| JS | A small JavaScript speed converter (km/h ↔ mph) |
| About Us | Why the site was made |

## Tech

HTML5 and CSS3 (one stylesheet per page), a little vanilla JavaScript, and AVIF images. No build step
or framework.

## Run locally

Open `index.html` in a browser.
